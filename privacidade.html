Política de privacidade

Esta política descreve o uso pessoal previsto do cliente OAuth Arca Backup com rclone e Google Drive. A conexão e a cópia externa ainda não foram validadas para recuperação.

Finalidade

O Arca Backup foi criado para autorizar o rclone a copiar para o Google Drive pessoal do responsável um conjunto de backup previamente criptografado pelo Déjà Dup. Se uma recuperação for necessária, o conjunto poderá ser baixado para restauração pelo Déjà Dup. A cópia externa e a restauração a partir dela ainda precisam de teste; esta política não afirma que já estejam disponíveis.

Acesso solicitado à conta Google

O escopo previsto é somente https://www.googleapis.com/auth/drive.file. Esse escopo limita o acesso do aplicativo aos arquivos e pastas que ele próprio criar no Drive. Não está previsto acesso geral a todos os arquivos da conta.

Onde ficam os dados

  • O conjunto criptografado pelo Déjà Dup permanece no armazenamento local; cópias feitas por este uso do rclone serão guardadas na conta Google pessoal do responsável pelo aplicativo.
  • Após uma autorização futura, o rclone armazenará o token de acesso no arquivo de configuração do próprio computador. O conteúdo desse arquivo deve ficar restrito ao usuário local. Estas páginas não recebem o token.
  • Estes arquivos de página são estáticos: não têm formulário, login, código de rastreamento ou dependências externas. Se publicadas, estas páginas serão hospedadas pelo GitHub Pages. O site estático não recebe tokens nem arquivos do backup. O GitHub poderá processar registros técnicos de acesso conforme suas próprias condições.

Revogação e exclusão

  1. Para revogar a autorização, acesse as conexões de aplicativos de terceiros na sua Conta Google, selecione Arca Backup, confira os detalhes e escolha remover o acesso. Revogar o acesso impede novos acessos do aplicativo, mas não apaga automaticamente os arquivos já guardados no Drive.
  2. Para excluir as cópias remotas, localize no Google Drive os arquivos e pastas criados para este backup, mova apenas os itens desejados para a lixeira e, se quiser exclusão definitiva, exclua esses itens da lixeira. Confira antes se possui outra cópia recuperável.

Não há política de exclusão automática da cópia remota configurada nesta etapa.
