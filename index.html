Arca Backup
Política de privacidade

Aplicativo OAuth pessoal

Uma cópia externa para o backup criptografado.

Arca Backup é o cliente OAuth pessoal planejado para conectar o rclone ao Google Drive. Seu uso previsto é copiar para a conta Google do responsável o conjunto de backup que o Déjà Dup já criptografou no computador e, quando necessário, baixá-lo para uma restauração.

Ler a política de privacidade

Como o uso foi planejado

01 · ORIGEM

Backup local

O Déjà Dup produz o conjunto criptografado no armazenamento local.

02 · CÓPIA

Envio ao Drive

O rclone, autorizado pelo cliente Arca Backup, deverá copiar esse conjunto para o Google Drive pessoal.

03 · RECUPERAÇÃO

Download e restauração

Em caso de necessidade, o conjunto remoto deverá ser baixado e usado em uma restauração com o Déjà Dup.

Estado atual

A conexão OAuth, a cópia externa do conjunto e a restauração a partir dela ainda não foram validadas. Esta página apenas apresenta o uso previsto; ela não autentica usuários nem transfere arquivos.
